# Baseforty

Express your happiness. Type 40 characters, earn $B40B.

## What is Baseforty?

Baseforty is an innovative decentralized application (dApp) built on Base Network that combines:
- Creative Content Generation - Type 40 unique characters per line
- Micro-Rewards - Earn 1 $B40B per line, 40 $B40B per block
- Proof of Humanity - Manual typing validates human participation
- Proof of Happiness - AI-assisted content from happy messages
- Gasless Rewards - No fees for users, all handled via CDP

# Description
Express your happiness with Baseforty. Simply type 40 characters, create, and earn.
Baseforty is an innovative dApp that converts users' Proof of Happiness (PoHss) messages into Proof of Humanity (PoH).

Proof of Happiness (PoHss) is an expression of happiness, love, longing, hearing music, smelling good, joy at a wedding, birthday, receiving flowers/gifts, etc., expressed/written in the form of a happy message.

Proof of Humanity is a manual input of 40 random characters by the user, validated 40x by the HASH System. The on-chain HASH validation system generates a unique block of data. Each successfully created block rewards the user with 40$B40B Content Coins. This process is repeatable indefinitely, with strict rules to maintain data uniqueness and integrity.  Built on Base (Coinbase L2), Baseforty combines a creative competition about everyone's Proof of Happiness expression with ongoing micro coin rewards and earning a Digital Proof of Humanity (PoH) Certificate. Next, a key milestone for a valid Baseforty Genesis Code (BGC), will be confirmed (minted) as a Digital Certificate. The name of this digital certificate is Baseforty PoH-Props, derived from Proof of Humanity Property Rights.

## How to Play

1. **Connect Wallet** - Use Base Wallet, MetaMask, or any Web3 wallet on Base Network
2. **Type 40 Characters** - All must be unique (no duplicates) or AI-assisted from happy messages
3. **Submit Lines** - Each valid line earns 1 $B40B
4. **Complete Block** - 40 lines = 40 $B40B reward (no gas fees!)
5. **Repeat** - Build blocks infinitely, progress to Genesis Code

## Features

### Dual Proof System
- **Proof of Humanity** - Manual typing (recommended)
- **Proof of Happiness** - AI-assisted from happy messages

### Reward System
- **1 $B40B per line** - Instant reward
- **40 $B40B per block** - Complete 40 lines
- **No gas fees** - Gasless transactions via CDP
- **40-minute timer** - Active period per block

### Block Progression
- Base1-Base40 (40 blocks)
- XBase1-XBase40 (1,600 blocks)
- YBase1-YBase40 (64,000 blocks)
- **Genesis Code** - Unique 40-digit code milestone
